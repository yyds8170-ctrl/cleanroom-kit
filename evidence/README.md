# 证据目录约定

本目录收纳各版本由 cleanroom-kit 命令在**真实浏览器**中跑出的可复跑验证产物。

## 目录结构

```text
evidence/
├── README.md            # 本约定说明
└── vX.Y.Z/              # 每个版本一个子目录，只记录本版新增/变更能力的验证
```

## 硬性约定

1. 证据必须来自真实浏览器运行，不允许用单元测试桩产物冒充；截图视口必须与命令参数一致。
2. 每个版本子目录内至少包含：真实截图（PNG）、结构化 JSON 报告、命令留档文本，以及本目录的 `README.md`。
3. 版本子目录的 `README.md` 固定小节：
   - **验证目标**：站点 URL 或本地目录 + 视口尺寸；
   - **执行命令**：逐条可复制的 `bin/crk ...` 命令；
   - **验收判据与结果**：指标阈值、实测值、通过/不通过；
   - **产物清单**：每个文件名 + 一句话说明；
   - **闭环记录**：本版「发现问题 → 修复 → 复验」过程。
4. 历史版本目录保持原样，不回改；新能力的验证只记入对应版本目录。
5. 本地复刻站点验证必须走 HTTP（`python3 -m http.server <端口>`），不使用 `file://`。
